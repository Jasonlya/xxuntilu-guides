# Obsidian 交互式学习网站 · GitHub Actions 自动归档与加密隔离方案

## 一、 核心目标与安全边界

这套方案用于支撑以下日常与分享场景：

1. **平时随手写、随手放**：新笔记或剪藏先丢进 `00-Inbox/`，不必一开始就纠结子目录或 Frontmatter 格式。
2. **GitHub Actions 自动加工与发布**：推送到 GitHub 后自动完成分类归档、生成派生索引并构建站点，减少手工整理成本。
3. **自己看全量，别人看公开部分**：公开分享版本自动剔除私密笔记与个人敏感数据；涉及私密随记或个人项目故事时，通过构建期过滤或浏览器端 AES-GCM 密码解锁隔离，避免明文随公开构建产物泄露。

> **安全红线**：前端界面隐藏按钮（如 `display: none`）不能算真正加密。只要私密笔记的明文被打包进公开网页产物或推送到公开仓库，查看源码或网络请求就能看到。因此必须采用**“构建期过滤/密文打包 + 浏览器端密码派生解密”**组合。

## 二、 整体架构设计

### 1. 公开版与私人版双轨流转

```text
[Obsidian 本地仓库]
  ├── 00-Inbox/               ──┐
  ├── 01-工具与中间件/        ──┼──> [git push] ──> [GitHub Actions]
  ├── 02-业务与工程实践/      ──┤                       ├── 1. AI 自动归档收件箱并回写仓库
  ├── 03-日常随记与灵感/      ──┤                       ├── 2. 加密或剔除私密笔记（99-Private / private: true）
  └── 99-Private/ (私密笔记)  ──┘                       └── 3. 构建公开分享站点（仅含公开内容 + 密文块）

[浏览端使用体验]
  ├── 访客 / 分享链接：仅见公开章节与公开结构，私密笔记不可见（或仅见密文锁屏）
  └── 自己（本地/解锁后）：输入主密码派生 AES-GCM 密钥，解锁私密笔记与本地加密故事/配置
```

### 2. 三种内容的隔离策略

| 内容类型 | 存放/标记方式 | 公开分享版表现 | 自己本地/解锁后表现 |
| :--- | :--- | :--- | :--- |
| **公开学习笔记** | 正常目录 + 未标记 `private: true` | 正常展示三栏教程、Tab、自测 | 正常展示 + 计入学习进度 |
| **私密随记/复盘** | `99-Private/` 目录或 `private: true` | **构建期直接剔除**（不进公开产物） | 仅本地可见，或输入密码 AES-GCM 解密后查看 |
| **个人项目故事/Key** | 浏览器 `LocalStorage` | 默认不展示个人填槽或需密码解锁 | 输入主密码派生密钥加解密，关页清内存密钥 |

## 三、 GitHub Actions 自动化工作流（`.github/workflows/publish-and-archive.yml`）

下面这份工作流完成三件事：
1. 自动归档 `00-Inbox/` 中非私密的新笔记并提交回仓库；
2. 在构建公开站点前，自动移除 `99-Private/` 与 Frontmatter 标记 `private: true` 的文件，确保公开产物零私密明文泄漏；
3. 自动完成 Next.js 构建并上传静态产物（可接 GitHub Pages 或 Vercel）。

```yaml
name: Archive Inbox & Build Public Study Hub

on:
  push:
    branches: [main]
    paths:
      - '00-Inbox/**.md'
      - 'content/00-Inbox/**.md'
      - '01-工具与中间件/**.md'
      - '02-业务与工程实践/**.md'
      - '03-日常随记与灵感/**.md'
      - 'src/**'
  workflow_dispatch:

permissions:
  contents: write
  pages: write
  id-token: write

jobs:
  archive-and-build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Python & Node
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Auto archive non-private inbox notes
        env:
          LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
          LLM_BASE_URL: ${{ vars.LLM_BASE_URL || '[https://api.deepseek.com/v1](https://api.deepseek.com/v1)' }}
          LLM_MODEL: ${{ vars.LLM_MODEL || 'deepseek-chat' }}
        run: |
          python - <<'EOF'
          import json, os, pathlib, urllib.request

          api_key = os.environ.get("LLM_API_KEY", "").strip()
          if not api_key:
              print("未配置 LLM_API_KEY，跳过自动归档")
              raise SystemExit(0)

          base_url = os.environ["LLM_BASE_URL"].rstrip("/")
          model = os.environ["LLM_MODEL"]

          inbox_dir = next((p for p in [pathlib.Path("00-Inbox"), pathlib.Path("content/00-Inbox")] if p.exists()), None)
          if not inbox_dir:
              raise SystemExit(0)

          parent = inbox_dir.parent if inbox_dir.parent != pathlib.Path(".") else pathlib.Path(".")
          folder_map = {
              "tool": parent / "01-工具与中间件",
              "interview": parent / "02-业务与工程实践",
              "note": parent / "03-日常随记与灵感",
          }

          for md in sorted(inbox_dir.glob("*.md")):
              raw = md.read_text(encoding="utf-8")
              # 含私密标记的草稿不送外部接口，也不自动外发归档
              if "private: true" in raw or "visibility: private" in raw:
                  print(f"跳过私密笔记: {md.name}")
                  continue

              prompt = f"""你是 Obsidian 知识库整理助手。请分析以下笔记并返回严格 JSON：
          1. docType 只能是 "tool"、"interview"、"note" 之一。
          2. formatted_markdown 为补全标准 YAML Frontmatter（含 title、type、topics、tags、updated）并整理排版后的完整 Markdown。
          仅输出 JSON：{{"docType": "...", "formatted_markdown": "..."}}

          笔记内容：
          {raw[:8000]}"""

              req = urllib.request.Request(
                  f"{base_url}/chat/completions",
                  data=json.dumps({
                      "model": model,
                      "messages": [{"role": "user", "content": prompt}],
                      "response_format": {"type": "json_object"},
                  }).encode("utf-8"),
                  headers={"Content-Type": "application/json", "Authorization": f"Bearer {api_key}"},
                  method="POST",
              )
              with urllib.request.urlopen(req, timeout=60) as resp:
                  content = json.loads(resp.read().decode("utf-8"))["choices"][0]["message"]["content"]
                  res = json.loads(content)

              target_dir = folder_map.get(res.get("docType", "note"), folder_map["note"])
              target_dir.mkdir(parents=True, exist_ok=True)
              (target_dir / md.name).write_text(res["formatted_markdown"], encoding="utf-8")
              md.unlink()
              print(f"已归档: {md.name} -> {target_dir}")
          EOF

      - name: Commit archived notes back to repo
        run: |
          if [ -n "$(git status --porcelain)" ]; then
            git config user.name "github-actions[bot]"
            git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
            git add -A
            git commit -m "chore(inbox): auto classify and archive notes"
            git push
          fi

      - name: Strip private notes before public build
        run: |
          python - <<'EOF'
          import pathlib, shutil

          removed = 0
          for p in list(pathlib.Path(".").rglob("*.md")):
              parts_lower = [x.lower() for x in p.parts]
              if ".git" in parts_lower or "node_modules" in parts_lower:
                  continue
              text = p.read_text(encoding="utf-8", errors="ignore")
              if "99-private" in parts_lower or "private: true" in text or "visibility: private" in text:
                  p.unlink()
                  removed += 1
          for d in list(pathlib.Path(".").rglob("*")):
              if d.is_dir() and ".git" not in d.parts and "node_modules" not in d.parts and "99-private" in d.name.lower():
                  shutil.rmtree(d, ignore_errors=True)
          print(f"公开构建前已剔除 {removed} 篇私密笔记")
          EOF

      - name: Install dependencies and build site
        env:
          PUBLIC_SHARE_MODE: "true"
        run: |
          npm ci
          npm run build
```

## 四、 前端加解密与“访客/私人解锁”实现

### 1. 浏览器原生 AES-GCM 加解密模块（`src/lib/vaultCrypto.ts`）

用于加密保存在 `LocalStorage` 中的“我的项目故事”、自定义 API Key 或前端密文片段，通过密码派生密钥，不硬编码密钥到源码中：

```typescript
// src/lib/vaultCrypto.ts

const enc = new TextEncoder();
const dec = new TextDecoder();

async function deriveAesKey(password: string, salt: Uint8Array): Promise<CryptoKey> {
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    enc.encode(password),
    'PBKDF2',
    false,
    ['deriveKey']
  );
  return crypto.subtle.deriveKey(
    {
      name: 'PBKDF2',
      salt,
      iterations: 150000,
      hash: 'SHA-256',
    },
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['encrypt', 'decrypt']
  );
}

export async function encryptVaultData(plainText: string, password: string): Promise<string> {
  const salt = crypto.getRandomValues(new Uint8Array(16));
  const iv = crypto.getRandomValues(new Uint8Array(12));
  const key = await deriveAesKey(password, salt);
  const encrypted = await crypto.subtle.encrypt({ name: 'AES-GCM', iv }, key, enc.encode(plainText));

  return btoa(
    JSON.stringify({
      s: Array.from(salt),
      iv: Array.from(iv),
      d: Array.from(new Uint8Array(encrypted)),
    })
  );
}

export async function decryptVaultData(cipherText: string, password: string): Promise<string> {
  const parsed = JSON.parse(atob(cipherText));
  const salt = new Uint8Array(parsed.s);
  const iv = new Uint8Array(parsed.iv);
  const data = new Uint8Array(parsed.d);
  const key = await deriveAesKey(password, salt);
  const decrypted = await crypto.subtle.decrypt({ name: 'AES-GCM', iv }, key, data);
  return dec.decode(decrypted);
}
```

### 2. 密码解锁弹窗组件（`src/components/VaultUnlockModal.tsx`）

仅在你主动点击“解锁个人保险箱”时弹出，密码只保存在当前 React 内存状态中，关闭或刷新页面后自动锁定：

```tsx
'use client';

import React, { useState } from 'react';
import { Lock, Unlock } from 'lucide-react';

interface Props {
  isUnlocked: boolean;
  onUnlock: (password: string) => Promise<boolean>;
  onLock: () => void;
}

export default function VaultUnlockModal({ isUnlocked, onUnlock, onLock }: Props) {
  const [open, setOpen] = useState(false);
  const [pwd, setPwd] = useState('');
  const [err, setErr] = useState('');
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!pwd.trim()) return;
    setLoading(true);
    setErr('');
    try {
      const ok = await onUnlock(pwd);
      if (ok) {
        setPwd('');
        setOpen(false);
      } else {
        setErr('密码错误或暂无已加密数据');
      }
    } catch {
      setErr('解密失败，请检查主密码');
    } finally {
      setLoading(false);
    }
  };

  if (isUnlocked) {
    return (
      <button
        onClick={onLock}
        className="flex items-center gap-1 px-2.5 py-1 rounded-md bg-emerald-50 text-emerald-700 border border-emerald-200 text-xs font-medium"
        title="点击立即锁定个人加密数据"
      >
        <Unlock className="w-3.5 h-3.5"/>
        已解锁（锁定）
      </button>
    );
  }

  return (
    <>
      <button
        onClick={() => setOpen(true)}
        className="flex items-center gap-1 px-2.5 py-1 rounded-md bg-slate-100 hover:bg-slate-200 text-slate-700 text-xs font-medium"
      >
        <Lock className="w-3.5 h-3.5"/>
        解锁私人区
      </button>

      {open && (
        <div className="fixed inset-0 z-50 bg-black/40 flex items-center justify-center p-4">
          <form
            onSubmit={handleSubmit}
            className="w-full max-w-sm rounded-2xl bg-white p-6 shadow-xl space-y-4 text-slate-800"
          >
            <h3 className="text-base font-bold">输入主密码解锁个人数据</h3>
            <p className="text-xs text-slate-500">
              密钥在本地通过 PBKDF2 + AES-GCM 派生，仅驻留当前会话内存，不会上传服务器。
            </p>
            <input
              type="password"
              value={pwd}
              onChange={(e) => setPwd(e.target.value)}
              placeholder="输入解锁密码..."
              autoFocus
              className="w-full px-3 py-2 rounded-lg border border-slate-200 text-sm focus:outline-none focus:ring-2 focus:ring-indigo-500"
            />
            {err && <p className="text-xs text-rose-600">{err}</p>}
            <div className="flex justify-end gap-2 pt-1">
              <button
                type="button"
                onClick={() => setOpen(false)}
                className="px-3 py-1.5 rounded-lg text-xs text-slate-500 hover:bg-slate-100"
              >
                取消
              </button>
              <button
                type="submit"
                disabled={loading}
                className="px-4 py-1.5 rounded-lg text-xs font-semibold bg-indigo-600 text-white hover:bg-indigo-700 disabled:opacity-50"
              >
                {loading ? '解锁中...' : '确认解锁'}
              </button>
            </div>
          </form>
        </div>
      )}
    </>
  );
}
```

## 五、 实施与上线检查清单

1. **配置 GitHub Secrets / Variables**：在仓库 `Settings -> Secrets and variables -> Actions` 中添加 `LLM_API_KEY`（按需添加 `LLM_BASE_URL`、`LLM_MODEL`）。
2. **验证收件箱归档**：在 `00-Inbox/` 放一篇测试笔记推送到 `main`，检查 Action 是否自动分类移动并提交回仓库。
3. **验证对外分享隔离**：在 `99-Private/` 放一篇含敏感词的测试笔记，触发公开构建后，在生成的页面产物和源码中检索该关键词，确认完全不存在。
4. **验证本地解锁流程**：在本地运行站点，填写项目故事并使用主密码加密保存，刷新页面后确认处于锁定状态，输入正确密码后可正常解密恢复。
